prompts.chat 是大型開源提示詞資料庫，本站已把 CSV 裡的角色與 prompt 範例匯入角色提示詞頁。它特別適合用來學角色型提示詞的結構：先定義角色、輸入方式、回答限制，再用第一句話啟動互動。

它也很適合當作 prompt library 產品參考，因為 repo 裡同時包含資料、書籍章節、網站介面、自架文件、MCP 與 API 設計。
